# PowerTorrent
A Powershell 5.1 BitTorrent client

<p align="center"><img src="https://github.com/illsk1lls/PowerTorrent/blob/main/.readme/PowerTorrent.png?raw=true"></p>

One script. Nothing else to install.

VPN Killswitch: Import a WireGuard `.conf` or OpenVPN `.ovpn` and torrent and search traffic go through the tunnel. If the VPN drops while the killswitch is on, that traffic stops. Save options to keep the config in `PowerTorrent.ini`.

Windows 10 or 11:

```powershell
.\PowerTorrent.ps1
```
